# Computer Vision & Image Processing Fundamentals

This repository contains a collection of Python scripts demonstrating fundamental Computer Vision techniques using **OpenCV** and **MediaPipe**. 

As a Computer Engineering student at **IZTECH** and a member of **Pars Team**, I studied these projects to explore real-time image manipulation, object detection, and facial landmaking.


##  Key Features
- **Real-Time Face Detection:** Implementation of a "Spiderman Mask" overlay using MediaPipe.
- **Image Processing Techniques:**
  - **Thresholding:** Global and Adaptive thresholding for document scanning and image segmentation.
  - **Edge Detection:** Canny edge detection with dilation and erosion operations.
  - **Contours:** Object detection based on background-foreground separation.
- **Core Operations:** Image/Video rescaling, drawing shapes, and handling real-time camera streams.


- **Language:** Python
- **Libraries:** OpenCV, NumPy, MediaPipe

Install dependencies:
    pip install opencv-python numpy mediapipe
